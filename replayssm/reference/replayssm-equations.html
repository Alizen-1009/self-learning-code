ReplaySSM 公式卡

全部公式取自 Tri Dao, ReplaySSM。标注「推导」的条目是本课程补出的，不是原文。

符号

S(nheads, d, n) recurrent state
S0(d, n) 检查点 state（只读）
v, u(d,) value / 伪 value
k, q(n,) key / query
h标量 buffer 中已缓存 token 数
L标量 buffer 容量
T标量 投机窗口长度
a, Δ, g, β标量/步 衰减与增益门
C(T, T) 投机窗口的严格下三角耦合（博客记作 As,s′）

衰减权重的箭头记号（本课程约定 · 第 3 课）

w(i → j) ≡ ai+1 · ai+2 ⋯ aj   ,   w(j → j) = 1 从位置 i 到位置 j 的累积衰减。凡本页出现 w，都是这个意思。第 1 课的 w0 = w(0→h)，wj = w(j→h)。

实现用前缀和，不做连乘（几十个 0.9 会下溢）：记 prej = Σi≤j log ai，则 log w(i→j) = prej − prei —— 一次前缀和出全部权重，任意区间的衰减都是两个前缀值相减。换回博客写法即 sj,t = Δj eA(pret−prej)（那个指数就是 log w(j→t)，Δj 是被折进 v 的增益）。

代价：前缀和有 cancellation / 下溢风险。flush 顺带把范围夹在 ≤ L 个 token 内 —— 这是它除省显存之外的第二个好处。此浮点结论为推理，未实测，需用 recurrent baseline 验证。

1 · Mamba-2

Summary route（基线）

St = at St−1 + Δt (vt kt⊤)  ,  yt = St qt

History route

St = Σi≤t ( Πi<j≤t aj ) Δi (vi ki⊤)

Output-only formulation

yt = āt (S0 qt) + Σj=1..h sj,t vj (kj⊤ qt) prej = Σi≤j Δi  ·  āt = eA·pret  ·  sj,t = Δj eA(pret−prej)
支点

(vj kj⊤) qt = vj (kj⊤ qt) —— dn 次乘法变 d+n 次，d×n 矩阵从不物化。

两步推导（推导 · 第 1 课）

第一步 · 展开递推。从检查点 S0 硬展开（增益折进 v，故递推为 St = atSt−1 + vtkt⊤）：

S1 = a1S0 + v1k1⊤
S2 = a2a1S0 + a2·v1k1⊤ + v2k2⊤
S3 = a3a2a1S0 + a3a2·v1k1⊤ + a3·v2k2⊤ + v3k3⊤ 每个历史外积只被「它诞生之后的所有 a」连乘。成立的唯一条件是 a 为标量（或对角 —— 见下方注）。
Sh = w0 S0 + Σj=1..h wj · vjkj⊤ w0 = Πi=1..h ai  ·  wj = Πi=j+1..h ai（故 wh = 1，最新 token 未衰减）。此步一分钱没省，仍物化 d×n。

第二步 · 右乘 q 并对每项用结合律。省下来的全靠这一步：

y = Shq = w0(S0q) + Σj wj·(vjkj⊤)q = w0(S0q) + Σj wj·vj·(kj⊤q)

与原始参数化的对应：实现不做连乘（会下溢），而在 log 空间用前缀和 log wj = preh − prej。换回博客写法即 sj,t = Δj eA(pret−prej) —— 也就是本页的 wj 乘上被折进 v 的那个增益 Δj。

分工（值得记住）

第一步（展开）买到的是「原始输入还在手上」→ 回滚与并行两个答案。第二步（结合律）买到的是「不必物化 d×n」→ 带宽那个答案。

Buffer 内容：{(vj, kj)}。路线：output-only。

2 · Gated DeltaNet

Summary route（基线）

St = egt St−1 (I − βt kt kt⊤) + βt (vt kt⊤)  ,  yt = St qt 右乘投影矩阵，无法直接展开成"检查点 + 加权和"。

替换：cache u 而非 v

St = αt St−1 + ut kt⊤ 一旦 ut 已知，形式就回到 Mamba-2，可以展开成衰减检查点 + uj kj⊤ 的加权和。

三行代数（推导 · 第 2 课）

记 αt = egt。把投影矩阵乘开，再合并共用同一个 kt⊤ 的两个外积：

α S(I − βkk⊤) + βvk⊤
= α S − αβ(S k)k⊤ + βvk⊤
= α S + [βv − αβ(S k)]k⊤
= α S + β(v − α(S k))k⊤ 合并能成立，是因为 delta rule 擦除的方向与写入的方向是同一个，两个外积右侧完全相同。
ut = βt ( vt − αt (St−1 kt) ) = 学习率 × (目标 − 预测)。就是 delta rule 的修正项，与 WY 表示的修正向量同源。
两个易错点（均已数值验证）

1. α 必须在括号内。预测要从已衰减的 state 读出。写成 β(v − S k) ⟹ 相对误差 31.8% —— 不够离谱，故极难抓。

2. 不能把 v 直接塞进 Mamba-2 的加权和。⟹ 相对误差 105%。

两条断言都写进了 code/verify_replayssm_identities.py（后者作为「必须失败」的测试）。

Buffer 内容：{(uj, kj, gj)}j=1..h。路线：state-and-output —— 一个 GDN step 需要在两个向量上读出（qt 出 y，kt 出 u），所以不能只走 output-only。

代价究竟在哪（推导 · 第 2 课，纠正早期说法）

不在带宽。St−1kt 这次额外读出，本身也能用 output-only 展开算（已验证，偏差 3e-15），所以 GDN 同样从不物化、从不写回 state。搬运量与 Mamba-2 几乎相同（buffer 每 token 多存一个标量门），只是算术翻倍：对检查点 2 次 mat-vec、窗口内 2h 次内积，算术强度 0.5 → 1.0 FLOP/byte。仍远低于 GPU 拐点，故带宽收益基本完整保留。

在串行纠缠。ut 依赖 St−1 依赖 u1..t−1，窗口内的 u 串成依赖链。普通 decode 无害（每步只新算一个，算完即冻结）—— 这正是必须 cache u 而非 v 的理由：cache v 就得每步重放整条链。但投机解码要同时求 T 个 u，链就成了拦路虎 → 下方三角求解。

投机验证：T×T 三角求解

us = Rs − Σs′<s C[s,s′] us′ 博客把它记作 As,s′；本课程改用 C，避免与衰减参数 A 撞名，并把「严格下三角」写进名字。

两半的定义（推导 · 第 3 课）

记 Sh 为窗口末端状态，w(i→j) 为 i 到 j 的累积衰减（见上方「符号」）。把 S(s 之前) 按第 1 课展开后代入 us = βs(vs − as·S(s 之前)ks)，再用 as·w(i→s−1) = w(i→s) 吸收：

Rs = βs ( vs − w(0→s) · (Sh ks) )
C[s,s′] = βs · w(s′→s) · (ks′⊤ ks)   (s′ < s，否则 0) R 完全不含 u ⟹ T 个可并行。耦合强度 ∝ 两个 draft 的 key 内积 ⟹ key 正交则 C = 0，完全解耦（已验证）。
(I + C) U = R   ⟹   U = (I + C)−1 R I + C 单位下三角 ⟹ 行列式恒为 1，永远可逆。T×T 足够小，可显式求逆退化成一次 GEMM —— 即 prefill 的 UT transform，只是 chunk 换成投机窗口。

输出侧是一次 causal-masked GEMM，无任何串行依赖：

ys = w(0→s) · (Sh qs) + Σs′≤s w(s′→s) · us′ · (ks′⊤ qs)
收益的准确表述

三角求解没有消灭串行依赖（前代法在 T 上仍串行），而是把它从「T 次昂贵的状态读出，每次 O(d(n+h))」压缩成「一个 T×T 小矩阵上的标量代入」—— 不碰检查点、不碰窗口、无新增显存流量。而后显式求逆把这点残余串行也变成 GEMM。

kernel 层含义：R 与 C 是上 tensor core 的大活，求逆是留在寄存器/SMEM 的小活。

Sh 全程不物化（Shks、Shqs 都走第 1 课的展开）。回滚 = 写指针停在 h + m；被拒的 u 从未进入状态，无需撤销。

3 · Cache / Flush

  1. 常规 step：把新输入 append 进 ring buffer，用内积公式算 yt。不读写完整 state（只读 S0）。
  2. Flush：当 h + 2T > L 时，把 buffer 汇总进 S0、清空 buffer、写回 HBM，并令 h = 0、write_pos = 0。
  3. 投机验证：draft append 进 buffer，用 masked GEMM 算 cached keys × draft queries。
  4. 回滚：把 write_pos 退到 h + m（m = 接受数），h ← h + m。零 state 恢复，零快照。

三个正确性不变量（第 4 课 · 破了都不抛异常）

  • h + 2T ≤ L

    ring buffer 不得覆盖仍需的输入。

    破了：重建的状态缺项 → 静默算错。已实测：L=4 → 282%、L=8 → 101%、L=16 → 37%、L=32 → 0.6%。L 越大错得越轻 ⟹ 越危险（像「精度问题」，能活到 benchmark）。

    为什么是 2T 而非 T：装下本轮只需 h+T≤L；多留一轮是因为 write_pos 每 forward 只能推进一次，不能在轮中间插入 flush，故须提前一轮保证最坏情况（m=T）也安全。此解释为本课程重建，博客未展开。

  • write_pos 每 forward 只前进一次

    CUDA graph 要求：推进次数不能依赖运行时才知道的 m。做法是先推进一次、事后回退。

    破了：graph 重放时指针步数与录制不一致 → 静默算错，且关掉 CUDA graph 症状就消失 —— 极易误判成 graph 的 bug。

    来源：SGLang RFC #28511。

  • flush 边界对齐 radix cache snapshot 边界

    ReplaySSM 的状态是 S0 + buffer 两部分；快照点若落在 buffer 中间，存下的 S0 不代表该 token 的状态。

    破了：别的请求复用错误快照 → 静默算错 + 跨请求污染。三条里最难定位（并发相关、不确定复现）。

    这是 RFC 要改 attention/mamba/mamba2_metadata.py 的原因。

回滚是精确的零（推导 · 第 4 课）

「接受 m 个后退指针」与「一开始只跑那 m 个」偏差 0.00e+00（不是 1e-15）。因为被拒 draft 的 u 虽写进了槽位，但 h 未计入，重建求和根本不遍历它们 —— 不是被减掉，是压根没被加进去。

L 的两侧约束（推导 · 第 4 课）

每步搬运 = 4dn + 4·h̄·(d+n) + 4dn/周期   ⟹   L* = √( 2dn/(d+n) ) 三项分别是读检查点、读 buffer、flush 摊薄写回。h̄ ≈ L/2。d=n=128 ⟹ L* ≈ 11，数值扫描得 12，收益 1.71×。极小很平坦（L=8–16 都约 1.70×）。

下界来自投机窗口：L ≤ 2T ⟹ h 恒为 0，buffer 一次都用不上；L ≥ 3T 才能连做两轮、buffer 才真正非空。两侧一撞（d=n=128）：

T下界 3T取该 L 的收益

4121.71×（刚好撞上最优）

16481.45×

投机窗口收两次费：第 3 课的 T² 内积（每 token 1 + T/(2h)），加这里的「抬高 L 下界、逼离带宽最优点」。两笔独立。
与第 1 课的关系：第 1 课算瞬时 h 的临界点 dn/(d+n)=64；这里是周期平均，故对应 L 的归零处是 2dn/(d+n)=128（已验证：L=128 ⟹ 1.00×）。
附带好处（推理，未实测）：flush 把衰减前缀和跨度夹在 ≤ L 内，可能改善数值稳定性。需用 recurrent baseline 在长序列上验证。

投机内积的精确计数（推导 · 第 3 课）

四份：R 的窗口部分 T·h、C 的 draft 间部分 T(T−1)/2、y 的窗口部分 T·h、y 的 draft 间部分 T(T+1)/2。合计 2Th + T²，每 token 摊到 2h + T；单步 decode 是 2h，故开销 1 + T/(2h)。

与博客 T(T+h) 的差异：T(T+h) 对应单条读出路径；GDN 走 state-and-output route，需要两条（出 u、出 y），故约为其两倍。两者同为 Θ(T(T+h))，二次项结论不变。Mamba-2 只需一条，接近 T(T+h) 本身。

二次项全部来自 draft 之间的两两 key 内积；窗口部分只贡献线性的 2Th。T=8,h=32 → 二次项占 11%，开销 1.13×；T=16,h=32 → 占 20%，开销 1.25×。

实测（博客 §6）

Nemotron-3（Mamba-2）与 Qwen3.5（GDN），至 550B，H100 / B300：kernel 1.43–1.84×，端到端 1.20–1.48×；投机吞吐 1.87–1.96×（对 vLLM baseline 至 2.14×）；固定 HBM 预算并发 3.0–3.3×。

对照：SGLang RFC #28511 的 microbench 为 kernel 1.2–1.5×，但 Qwen3.5 MoE 端到端仅 ~2.3% TPOT —— MoE 中 GDN 层占比低，Amdahl 上限压住了收益。

Amdahl 换算（第 5 课 · f = GDN 占比，x = 局部加速，E = 端到端）
