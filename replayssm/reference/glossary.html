ReplaySSM 术语表

本工作区所有课程统一使用这里的定义。与 linear_attn 术语表 互补：那份覆盖 prefill / chunk，这份覆盖 decode。

核心概念

Summary route（摘要路线）

每步立即把新输入吸收进 recurrent state，然后丢弃原始输入。state 是唯一真相来源。标准 SSM decode 的做法。代价：每步读写整个 d×n；有损，不可回滚；串行。

History route（历史路线）

把递推展开，state 表示为「一个衰减过的检查点 + 最近若干原始输入的加权和」。与 summary route 数学等价，区别只在于内存里留的是输入还是摘要。ReplaySSM 的基础。

Output-only formulation（仅输出形式）

在 history route 上再用一次结合律 (v k⊤) q = v (k⊤ q)，直接算出 yt，完全不物化 state 矩阵。Mamba-2 走这条路。

State-and-output route（状态与输出形式）

每步需要在两个向量上读出的形式：qt 出 yt（这一层的输出），kt 出预测、进而出 ut（喂给自己的状态更新）。GDN 走这条路。

⚠️ 注意它不意味着要物化 state。St−1kt 与 St−1qt 形式相同，同样能用 output-only 展开算出（已数值验证，偏差 3e-15）。GDN 与 Mamba-2 一样从不写回 state；差别只是算术翻倍（0.5 → 1.0 FLOP/byte，仍 memory-bound）与窗口内 u 的串行纠缠。详见第 2 课。

检查点 state（checkpoint state, S0）

buffer 窗口之前所有历史的摘要，(d, n)。常规 step 中只读不写；只在 flush 时更新并写回 HBM。

Ring buffer（环形缓冲）

存放最近 h 个 token 原始输入的定长循环队列，容量 L。Mamba-2 存 (v, k)；GDN 存 (u, k, g)。回滚 = 移动写指针。

Flush（汇总冲刷）

把 buffer 内的输入汇总进 S0、清空 buffer、写回 HBM。投机场景判据 h + 2T > L。这是唯一发生 state 写回的时刻，成本被摊薄到 4dn/L 每步。

伪 value（u）

GDN 中让更新退化成 St = αt St−1 + ut kt⊤ 的那个向量。它就是 delta rule 的修正项 —— 与 WY 表示里的修正向量同源（见 linear_attn 第 3 课）。ReplaySSM 的 GDN 版本 cache u 而不是 v。

Decode 与投机解码

Decode（解码步）

序列长度为 1 的前向。chunk 消失，GEMM 退化成 mat-vec，算术强度掉到 ~1 FLOP/byte —— 与 prefill 的 compute-bound 局面相反，这里是 memory-bound。

投机窗口（T）

一轮投机解码提出的 draft token 数量。ReplaySSM 中它带来 Θ(T(T+h)) 的额外内积开销（GDN 精确为 2Th + T²，每 token 开销 1 + T/(2h)）—— 这是换取并行验证付出的代价。见第 3 课 · 第 4 课。

State 快照（state snapshot）

ReplaySSM 要消灭的东西。既有投机解码方案为了能回滚，给每个 draft token 存一份完整 d×n state，搬运量乘上 T，并发被显存挤死。参见 Snakes and Ladders。

Masked GEMM（掩码矩阵乘）

投机验证的核心操作：一次算出 cached keys 与全部 draft queries 的内积，用 causal mask 屏蔽不该看到的位置。取代逐 draft 的串行循环。

三角求解（triangular solve）

GDN 投机验证中解 us = Rs − Σs′<s C[s,s′] us′ 的手段。C 严格下三角（博客记作 As,s′；本课程改用 C，避免与衰减参数 A 及 buffer 容量 L 撞名），T×T 规模，一次解出全部 T 个修正项。与 prefill 里 UT transform 求 (I − tril(A))−1 是同一类操作，只是这里的"chunk"是投机窗口而不是序列 chunk。

TPOT（time per output token）

每输出 token 的时间，decode 阶段的核心端到端指标。注意 kernel 加速 ≠ TPOT 加速：MoE 模型里 GDN 层占比低，Amdahl 上限会把收益压到很小（SGLang 实测 Qwen3.5 仅 ~2.3%）。

Amdahl 换算（f / x / E）

第 5 课符号：f = GDN decode 占端到端时间比例，x = 局部（kernel）加速，E = 端到端加速。E = 1/((1−f) + f/x)，反推 f = (1−1/E)/(1−1/x)，上限 1/(1−f)。两条体检规则：E ≤ x 恒成立；区间读数必须配对（错配会推出 f > 1）。MoE 实测反推 f ≈ 8.7%（上限 1.095×），博客 dense 配置 f ≈ 55–71%。Amdahl 只压时间轴：显存/并发（3.0–3.3×）与投机解锁（1.87–1.96×）不受 f 压制。见第 5 课。

沿用 linear_attn 的术语

以下概念在 linear_attn 术语表中已定义，本工作区直接沿用，不重复：chunk、causal mask M、衰减权重矩阵 D、WY 表示、UT transform、gated delta rule、persistent kernel、算术强度。

对应关系

decode 侧的 sj,t 就是 prefill 侧衰减权重矩阵 D 的最后一行。decode 侧的 T×T 三角求解就是 prefill 侧 UT transform 在投机窗口上的复用。ReplaySSM 很大程度上是把训练/prefill 的 chunk 技巧搬到 decode。
