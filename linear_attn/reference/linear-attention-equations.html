Order matters

当前 token 的 update 先进入状态，再由 query 读取，才能包含 causal attention 的对角线。

Causal mask

C = 4
M = [[1, 0, 0, 0],
     [1, 1, 0, 0],

     [1, 1, 1, 1]]

工程判断

  • Recurrent：每 token 工作量固定，但时间维串行；适合 decode。
  • Chunk：块内转为 GEMM，块间保留 state recurrence；适合 prefill/training。
  • 更大的 C：通常提高 GEMM 规模，但增加块内二次工作和数值压力。
  • GDN/KDA：不推翻这个骨架，而是改变 state transition 与块内 correction。
