Linear Attention
公式速查

从 causal attention、recurrent state 到一个 chunk 的最小公式集。

Shape 约定（单 head）

Token vectorsq,k:[K] · v,o:[V]
Recurrent stateS:[K,V]
Chunk inputsQ,K:[C,K]
Chunk valuesV,O:[C,V]

Causal Linear Attention

ot = Σi≤t(qtᵀki)vi
ot = qtᵀ(Σi≤tkiviᵀ)

Recurrent form

St = St−1 + ktvtᵀ
ot = qtᵀSt
Order matters

当前 token 的 update 先进入状态，再由 query 读取，才能包含 causal attention 的对角线。

One-chunk form

O = Q·Sin + ((Q·Kᵀ) ⊙ M)·V
Sout = Sin + Kᵀ·V
Inter

Q·S_in

过去 chunks 的贡献。

Intra

((Q·Kᵀ)⊙M)·V

当前 chunk 的 causal 贡献。

Causal mask

C = 4
M = [[1, 0, 0, 0],
     [1, 1, 0, 0],
     [1, 1, 1, 0],
     [1, 1, 1, 1]]

Scalar-gated recurrent

St = exp(gt)·St−1 + ktvtᵀ
Gi = Σm=0..igm

Scalar-gated chunk

Dij = 1[j≤i]·exp(Gi−Gj)
O = (Q⊙exp(G))·Sin + ((QKᵀ)⊙D)·V
Sout = exp(Glast)·Sin + (K⊙exp(Glast−G))ᵀ·V
退化检查

所有 g=0 时，G=0、D=M，回到 vanilla LA。

Delta Rule（先令 g=0）

rt=βt(vt−ktᵀSt−1)
St=St−1+ktrtᵀ

Delta chunk / WY-style

L=tril(KKᵀ,−1), B=diag(β)
T=(I+BL)⁻¹B
U=TV, W=TK, R=U−WSin
Sout=(I−KᵀW)Sin+KᵀU
Mask distinction

Residual dependency的 L 使用严格下三角；output 的 tril(QKᵀ) 包含对角线。

Gated Delta chunk

Gi=Σm≤igm
Lij=1[j<i]exp(Gi−Gj)kiᵀkj
T=(I+BL)⁻¹B; U=TV; W=T(K⊙exp(G)); R=U−WSin
Pij=1[j≤i]exp(Gi−Gj)qiᵀkj
O=(Q⊙exp(G))Sin+PR
Sout=exp(Glast)Sin+(K⊙exp(Glast−G))ᵀR

工程判断

  • Recurrent：每 token 工作量固定，但时间维串行；适合 decode。
  • Chunk：块内转为 GEMM，块间保留 state recurrence；适合 prefill/training。
  • 更大的 C：通常提高 GEMM 规模，但增加块内二次工作和数值压力。
  • GDN/KDA：不推翻这个骨架，而是改变 state transition 与块内 correction。
