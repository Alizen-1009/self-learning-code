判断规则

grid 含 NT → chunks 可并行
program 内 for NT → chunks 串行

FLA

Gate       grid=(NT, B×H)          parallel chunks
KKT/Solve  grid=(NT, B×HV)         parallel chunks
W/U        grid=(NT, B×HV)         parallel chunks
State      grid=(Vtiles×N×HV,)     for chunk: serial
Output     grid=(Vtiles,NT,B×HV)   parallel chunks
parallel local prep → serial state scan → parallel output
  • H[c]：chunk c incoming state；
  • v_new[c]：chunk c corrected residual；
  • 两者写 global memory，供独立 output kernel 使用。

FlashInfer SM100/SM103

persistent grid ≈ min(B×H, clusters)

CTA(sequence, head):
    load state → TMEM
    for chunk:
        local prep + output + state update
    store final state
  • chunk=64，但 chunk 不在 grid 中；
  • state 跨 chunks 常驻 TMEM；
  • 不物化完整 global H/W/U/v_new；
  • 依赖 B×H 提供 CTA 并行度。
