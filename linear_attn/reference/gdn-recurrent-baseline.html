第 6 课 Prefill 调度

Contract

q/k/v        BF16 [B,T,H,128]
alpha/beta   FP32 [B,T,H]
state in/out FP32 [B,H,V,K]
output       BF16 [B,T,H,V]
q/k normalized; q already scaled

Token semantics

S←αS
r←β(v−Sk)
S←S+r·kᵀ
o←Sq

Triton schedule

grid = (B×H, ceil(V/16))
program state tile = [16,128]
parallel: B / H / V tiles
serial: token loop

CuTe DSL schedule

grid = B×H×(128/16)
1 CTA = 1 warp = 16 V rows
K: 16 lane groups × vec8
V: 2 lane rows × 8 rows
state: FP32 registers across T

B300 result

8 / 8 PASS
max output rel-L2 = 2.820e-5
max state rel-L2 = 7.921e-8

用途：作为后续 chunk GDN 的 output/final-state correctness oracle；不是性能目标。
