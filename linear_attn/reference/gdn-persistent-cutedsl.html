教学 SM103-style

7 GEMMs → UMMA

Production SM90

grid = sequence×head
block = 4 warpgroups = 512 threads
WG0 load/store
WG1/WG2 state math registers
WG3 KK/QK/inverse
WGMMA; no TMEM
