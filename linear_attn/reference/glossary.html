第 1 课 公式表

核心术语

Linear Attention（LA）
利用可结合的 kernel/feature-map 形式，把历史 token 压缩进固定大小状态，避免显式保存完整 T×T attention matrix。
Recurrent form
按 token 更新状态并立即产生输出的等价表达。时间维串行，适合短序列或 decode。
State（S）
历史 key/value 的压缩表示。本文 K-first 约定下 shape 为 [K,V]；部分 kernel 使用转置的 V-first [V,K]。
Chunk
连续的 C 个 token。chunk 内依赖尽量改写成 GEMM，chunk 间通过 state 连接。
Inter-chunk
当前 chunk 与更早 chunks 之间的交互，例如 vanilla LA 的 Q·S_in。
Intra-chunk
同一个 chunk 内 token 的因果交互，例如 ((QKᵀ)⊙M)V。
Prefill
一次处理较长 prompt 的阶段，token 并行度高，通常适合 chunk/GEMM/Tensor Core 路径。
Decode
自回归生成阶段，通常每步只有一个或少量 token，更关注 state 读写、GEMV、launch latency 和 batch 并行度。
Gate / decay
控制旧状态保留比例的量。GDN 常为每 head 标量；KDA 为每个 key dimension 一个值。
Delta rule
用当前 value 与状态预测值之间的 residual 做 rank-1 correction，而不是无条件累加 k·vᵀ。
WY representation
把一组依赖更新改写为块矩阵形式，使 chunk 内 correction 可通过三角求解和 GEMM 计算。后续 GDN/KDA 课程展开。

该术语表会随课程扩展；发现项目间命名冲突时，以 shape 和公式为最终依据。
