完成标准

不看资料，能写出下面三个式子，并解释 inter-chunk 与 intra-chunk 各是哪一项。

O = Q·Sin + ((Q·Kᵀ) ⊙ M)·V
Sout = Sin + Kᵀ·V 这里先研究无归一化、无 gate 的 causal Linear Attention；M 是含对角线的下三角 mask。

这一步直接服务于使命：后续 GDN/KDA 的 chunk kernel 虽然会加入 decay、delta correction 和三角求解，但仍围绕“进入块的状态 + 块内因果贡献 + 离开块的状态”组织。

1｜先把二次注意力折成一个状态

对 causal、无 softmax 的 Linear Attention，token t 只能看见 i ≤ t：

ot = Σi≤t (qtᵀki)vi

标量内积可以和 value 的加权重新结合：

  1. 把 query 提到求和外。
    ot = qtᵀ (Σi≤t kiviᵀ)
  2. 给括号里的矩阵命名。
    St := Σi≤t kiviᵀ
  3. 得到递推。
    St = St−1 + ktvtᵀ
    ot = qtᵀSt
query / keyqₜ, kₜ : [K]
value / outputvₜ, oₜ : [V]
rank-1 updatekₜvₜᵀ : [K,V]
recurrent stateSₜ : [K,V]
关键判断

复杂度从显式构造 T×T attention matrix，变成每个 token 更新固定大小的 K×V 状态。但时间维仍然有递推依赖：Sₜ 必须等 Sₜ₋₁。

2｜把 C 个 token 合成一个 chunk

取连续的 C 个 token，堆叠成：

Q / K[C,K]
V / O[C,V]

这个 chunk 开始前已经有状态 S_in。对 chunk 内第 r 行：

or = qrᵀSin + Σj≤r(qrᵀkj)vj
Inter-chunk

Q·S_in

来自更早 chunk 的压缩状态。每个 chunk 之间仍有递推依赖。

Intra-chunk

((Q·Kᵀ) ⊙ M)·V

当前 chunk 内的 causal 交互。它变成规则 GEMM，是 GPU 并行化的入口。

把所有行堆叠起来，就得到本课目标公式：

O = Q·Sin + ((Q·Kᵀ) ⊙ M)·V

chunk 处理完后，所有 C 个 rank-1 update 都进入状态：

Sout = Sin + Σj=1..Ckjvjᵀ = Sin + Kᵀ·V
C = 2 的展开检查

o₀ = q₀ᵀS_in + (q₀ᵀk₀)v₀

o₁ = q₁ᵀS_in + (q₁ᵀk₀)v₀ + (q₁ᵀk₁)v₁

下三角 mask 正好删除未来项 (q₀ᵀk₁)v₁。

真正的洞察

Chunk 没有改变数学语义，它改变的是调度。 时间维从“每个 token 都串行”变为“chunk 内并行 GEMM、chunk 间递推”。chunk size 是并行度、额外块内计算、状态通信和数值稳定性的折中。

3｜把公式翻译成最小 PyTorch

def recurrent_la(q, k, v):
    # q, k: [T, K]   v: [T, V]
    T, K = q.shape
    V = v.shape[-1]
    state = q.new_zeros(K, V)
    out = []
    for t in range(T):
        state = state + torch.outer(k[t], v[t])
        out.append(q[t] @ state)
    return torch.stack(out), state


def one_chunk_la(q, k, v, state_in):
    # q, k: [C, K]   v: [C, V]   state_in: [K, V]
    C = q.shape[0]
    mask = torch.tril(torch.ones(C, C, device=q.device))
    intra = ((q @ k.T) * mask) @ v
    inter = q @ state_in
    state_out = state_in + k.T @ v
    return inter + intra, state_out

动手任务：用随机的 T=8, K=4, V=3, C=4 输入，连续调用两次 one_chunk_la，验证它与 recurrent_la 的 output/final state 一致。

代码语义可继续对照 FLA 的 naive Linear Attention。理论来源见 Katharopoulos et al., Transformers are RNNs。
