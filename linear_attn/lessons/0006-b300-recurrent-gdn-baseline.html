1｜先锁定 Phase-1 contract

这节课只实现 GDN 核心 recurrence，所有前处理已经完成：

q / k / vBF16 [B,T,H,128]
alpha / betaFP32 [B,T,H]
stateFP32 [B,H,V,K]
outputBF16 [B,T,H,V]
  • q 已 L2 normalize 并乘 1/sqrt(128)；
  • k 已 L2 normalize；
  • alpha 是乘法 forget gate；
  • beta 是已激活 update rate；
  • 固定 K=V=128，暂不支持 varlen/GVA/state pool。
为什么先分阶段

如果第一版同时融合 norm、raw gate、sigmoid、varlen 和 state pool，输出不一致时无法判断是 recurrence 错还是前处理 contract 错。

2｜PyTorch oracle：唯一语义来源

for t in range(tokens):
    state = state * alpha[:, t, :, None, None]
    prediction = torch.einsum("bhvk,bhk->bhv", state, k[:, t])
    residual = beta[:, t, :, None] * (v[:, t] - prediction)
    state = state + residual.unsqueeze(-1) * k[:, t].unsqueeze(-2)
    output[:, t] = torch.einsum("bhvk,bhk->bhv", state, q[:, t])

state 使用 V-first：

state[b,h,v,k]

因此每个 V row 都可以独立计算：

prediction[v] = Σₖ state[v,k]·key[k]

这给两个 GPU baseline 提供了最自然的切分轴：按 V rows 分 tile。

3｜Triton baseline：一个 program 管 16 个 V rows

grid = (B × H, ceil(V / 16))

一个 Triton program 持有：

state tile [16,128]，FP32
bh = tl.program_id(0)
v_tile = tl.program_id(1)
state = load_state_tile(v_tile)          # [16,128]

for t in tl.range(0, T):                 # token recurrence 串行
    state *= alpha[t]
    prediction = tl.sum(state * key[None, :], axis=1)
    residual = beta[t] * (value - prediction)
    state += residual[:, None] * key[None, :]
    output = tl.sum(state * query[None, :], axis=1)

store_final_state_tile(state)

哪里并行？

  • 不同 batch/head 并行；
  • 同一 state 的不同 16-row V tiles 并行；
  • 每个 row 对 K=128 的 reduction 由 Triton threads 协作。

哪里串行？

同一 sequence/head/V-tile 的 token loop 串行，因为 token t+1 需要 token t 更新后的 state。

4｜CuTe DSL baseline：一个 warp 管 16 个 V rows

CuTe 版使用与 FlashInfer recurrent KDA 类似的 register-tile schedule：

grid = B × H × (128 / 16)，每 CTA 1 warp
K partition16 lane groups × vec8
V partition2 lane rows × 8 rows
state/thread8 rows × 8 K values
accumulationFP32 registers

每个线程先加载自己负责的 state 元素；q/k 由 32 lanes 分片加载，再通过 warp shuffle 广播给两个 V lane groups：

for token in cutlass.range_constexpr(T):
    load_qk_fragments()
    q_vec8 = warp_shuffle_broadcast(q_fragment)
    k_vec8 = warp_shuffle_broadcast(k_fragment)

    for owned_v_row in rows:
        state_row *= alpha
        prediction = butterfly_reduce(dot8(state_row, k_vec8))
        residual = beta * (value - prediction)
        state_row += residual * k_vec8
        output = butterfly_reduce(dot8(state_row, q_vec8))

这里没有使用 TMEM/Tensor Core；它是教学用 correctness baseline。后续 chunk 版才会把工作转为 GEMM，并使用 Blackwell 的 TMEM/UMMA。
