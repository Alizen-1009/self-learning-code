0｜先取回上一课的 M

不回看第一课：对于 chunk 内 query 行 i 和 key 列 j，什么时候 M[i,j]=1？

M[i,j] = 1[j ≤ i]。它是包含对角线的下三角 causal mask。

这一课 M 不会消失。它仍负责“能否看到”，新加入的 decay 只负责“能看到多少”。

完成标准

能从 scalar-gated recurrence 独立写出加权下三角矩阵 D、chunk output 和 chunk final state。

Dij = 1[j≤i] · exp(Gi−Gj)

1｜从一个 scalar gate 开始

令 gₜ ≤ 0 是 log-space gate，实际保留率为 αₜ = exp(gₜ)。先只加入 forget gate，不加入 delta correction：

St = exp(gt)·St−1 + ktvtᵀ
ot = qtᵀSt
先分清语义

旧状态在写入当前 kₜvₜᵀ 之前衰减。因此当前 token 的自身贡献系数仍是 1；更早 token 会按经过的 gate 连乘。

在一个 chunk 内定义 cumulative log-decay

Gi := Σm=0..i gm

把 recurrence 展开到 chunk 内第 i 个 token：

Si = exp(Gi)·Sin + Σj≤i exp(Gi−Gj)·kjvjᵀ
  1. exp(Gᵢ)：进入 chunk 前的状态要经过 token 0 到 i 的全部 gate。
  2. exp(Gᵢ−Gⱼ)：token j 的新写入只经过 j 之后到 i 的 gate；当 i=j 时指数为 0，系数为 1。
  3. j≤i：仍由 causal mask 保证不能读取未来。
C = 2 展开

S₀ = exp(g₀)S_in + k₀v₀ᵀ

S₁ = exp(g₀+g₁)S_in + exp(g₁)k₀v₀ᵀ + k₁v₁ᵀ

其中 exp(g₁) = exp(G₁−G₀)。

2｜M 变成带权重的 D

上一课的 M 只包含 0/1。现在定义：

Dij := Mij · exp(Gi−Gj)

因此：

  • j > i：未来位置，D[i,j]=0；
  • j = i：当前 token，D[i,i]=1；
  • j < i：历史 token，权重是从 j 之后到 i 的累计衰减。

Chunk output

将 oᵢ=qᵢᵀSᵢ 对所有行堆叠：

O = (Q ⊙ exp(G))·Sin + ((Q·Kᵀ) ⊙ D)·V
Inter-chunk

(Q⊙exp(G))·S_in

incoming state 到每个 query 位置要经过不同长度的 decay。

Intra-chunk

((QKᵀ)⊙D)·V

causal mask 与相对 decay 一起作用于块内 score。

Chunk final state

令 G_last=G[C−1]，chunk 末状态是：

Sout = exp(Glast)·Sin + (K ⊙ exp(Glast−G))ᵀ·V

这里 exp(G_last−G) 按 K 的 token 行缩放；越早的 key 到 chunk 末尾时衰减越多。

退化检查

若所有 g=0，则 G=0、D=M，三个公式精确退化回上一课的 vanilla LA。推导新公式时，退化检查是最便宜的 correctness test。

3｜最小 PyTorch reference

def recurrent_gla(q, k, v, g, state):
    # q,k:[T,K]  v:[T,V]  g:[T]  state:[K,V]
    out = []
    for t in range(q.shape[0]):
        state = g[t].exp() * state + torch.outer(k[t], v[t])
        out.append(q[t] @ state)
    return torch.stack(out), state


def one_chunk_gla(q, k, v, g, state_in):
    # q,k:[C,K]  v:[C,V]  g:[C]
    C = q.shape[0]
    G = g.cumsum(0)
    M = torch.tril(torch.ones(C, C, device=q.device))
    D = (G[:, None] - G[None, :]).exp() * M

    inter = (q * G.exp()[:, None]) @ state_in
    intra = ((q @ k.T) * D) @ v

    k_to_end = k * (G[-1] - G).exp()[:, None]
    state_out = G[-1].exp() * state_in + k_to_end.T @ v
    return inter + intra, state_out

数值警告

公式可以写成 exp(Gᵢ)·exp(−Gⱼ)，但当累计 decay 很负时，单独计算 exp(−Gⱼ) 可能溢出。生产 kernel 更倾向直接计算局部差值、使用 offset，或转换到 base-2 指数。后续 KDA safe-gate 课程会回到这个问题。
