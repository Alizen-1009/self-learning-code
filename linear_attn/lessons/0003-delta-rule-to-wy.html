0｜先取回旧模型

Vanilla LA 中，一个 chunk 对状态做什么？

S_out = S_in + KᵀV。每个 token 无条件写入 kᵢvᵢᵀ，所以所有 value 可以直接堆成一次矩阵乘。

Delta Rule 改变的正是“无条件写入”：它先问状态已经预测出了多少，只写入预测误差。

完成标准

看到 recurrent delta update 后，能独立写出 residual 的下三角线性系统，并解释为什么 R = U − W·S_in。

(I + B·L)·R = B·(V − K·Sin)
R = U − W·Sin L 是严格下三角 key Gram matrix；B=diag(β)；U=T·V，W=T·K。

1｜Delta Rule 只写预测误差

这一课先令 decay g=0，隔离 delta correction。使用 K-first state S:[K,V]：

pt = ktᵀSt−1
rt = βt·(vt − pt)
St = St−1 + ktrtᵀ
predictionpₜ:[V]
residualrₜ:[V]
update rateβₜ:scalar
state updatekₜrₜᵀ:[K,V]

如果状态已经能从 kₜ 预测出 vₜ，residual 接近 0，就不需要重复写入；如果预测错误，才沿着 key 方向修正。

不要混淆 β

β 是 delta update rate，不是 forget gate。GDN 中通常同时存在 scalar decay exp(g) 和 update rate β。

2｜为什么不能再直接写 KᵀV

在 chunk 开始前有 S_in。第一个 residual：

r₀ = β₀·(v₀ − k₀ᵀSin)

第二个 token 看到的状态已经包含第一个 residual：

r₁ = β₁·(v₁ − k₁ᵀSin − (k₁ᵀk₀)r₀)

第三个 residual 又依赖 r₀ 和 r₁。一般地：

ri = βi·(vi − kiᵀSin − Σj<i(kiᵀkj)rj)
依赖方向

rᵢ 只依赖更早的 rⱼ, j<i，所以依赖矩阵是严格下三角；对角线不在 L 中，因为当前 residual 还没有写入状态。

3｜把逐行依赖堆成三角系统

把 chunk 内 residual 堆为 R:[C,V]，并定义：

update-rate matrixB=diag(β):[C,C]
strict key GramL=tril(KKᵀ,−1):[C,C]

所有逐 token 方程可以一次写成：

R = B·(V − K·Sin − L·R)

把含 R 的项移到左边：

(I + B·L)·R = B·(V − K·Sin)

I+B·L 是对角线全 1 的下三角矩阵，因此可以通过 forward substitution / triangular solve 求 R：

T := (I + B·L)−1·B
R = T·(V − K·Sin)
“逆”不等于真的求通用逆

数学上写 inverse 方便推导；实现中应利用下三角结构做 solve、递推展开或有限级数。生产 kernel 不会调用一个通用 dense inverse。

4｜W/U 把 state 依赖分离出来

将 T 分别作用在 value 和 key 上：

U := T·V    [C,V]
W := T·K    [C,K]

于是 residual 可以写成：

R = U − W·Sin
U

只依赖当前 chunk 的 K/V/β。

可以在不知道 incoming state 时并行预计算。

W

描述 incoming state 如何影响 residual。

与 S_in 相乘后得到 chunk 对历史预测的 correction。

Chunk final state

Sout = Sin + Kᵀ·R

代入 R=U−W·S_in：

Sout = (I − KᵀW)·Sin + KᵀU

这就是一个 chunk 对 state 的仿射变换：左边矩阵负责传播/修正旧状态，右边矩阵负责写入当前 chunk 的新信息。这类紧凑表示常被称为 WY-style representation。

Chunk output

令 P=tril(QKᵀ)，这里包含对角线，因为 query 要读取当前 token 更新后的状态：

O = Q·Sin + P·R
= Q·Sin + P·(U − W·Sin)
Kernel 视角

串行 residual recurrence 被拆成 KKᵀ、小三角 solve、TV/TK、W·S、KᵀR 等矩阵操作。这正是 chunk 算法获得 Tensor Core 并行机会的位置。

5｜最小 PyTorch reference

def recurrent_delta(q, k, v, beta, state):
    out = []
    for t in range(q.shape[0]):
        residual = beta[t] * (v[t] - k[t] @ state)
        state = state + torch.outer(k[t], residual)
        out.append(q[t] @ state)
    return torch.stack(out), state


def one_chunk_delta(q, k, v, beta, state_in):
    C = q.shape[0]
    strict = torch.tril(torch.ones(C, C, device=q.device), -1)
    L = (k @ k.T) * strict
    B = torch.diag(beta)
    left = torch.eye(C, device=q.device) + B @ L

    # T = (I + B L)^(-1) B；实现用 triangular solve
    T = torch.linalg.solve_triangular(left, B, upper=False)
    U = T @ v
    W = T @ k
    R = U - W @ state_in

    P = (q @ k.T) * torch.tril(torch.ones_like(L))
    out = q @ state_in + P @ R
    state_out = state_in + k.T @ R
    return out, state_out

映射到 FLA

打开 naive_chunk_gated_delta_rule，对照：

strict lower key Gram     → attn 的初始下三角项
triangular inverse/solve  → attn 的逐行递推
U = T @ V                 → k_cumsum / u
W = T @ K                 → k_cumdecay / w
R = U - W @ S_in          → v_new
S_out = ... + K.T @ R     → chunk state update

FLA 文件还融合了 scalar decay，所以实际 W/K/Q 带有 exp(G) 的缩放；但三角系统和 R=U−WS 的骨架不变。

符号约定警告

不同论文/代码可能把负号吸收到 L、A 或 W 中，也可能直接保存 (I+BL)⁻¹ 而不是 T。不要靠变量名判断；检查它最终是否满足逐行 residual 方程。
