1｜一个 token 的执行顺序

Gated Delta Rule 对每个 token 做四步：

  1. Decay：S̄ₜ = exp(gₜ)·Sₜ₋₁
  2. Predict：pₜ = kₜᵀS̄ₜ
  3. Correct：rₜ = βₜ(vₜ−pₜ)
  4. Write / Read：Sₜ=S̄ₜ+kₜrₜᵀ，oₜ=qₜᵀSₜ
顺序决定公式

先 decay，再用衰减后的状态预测；当前 residual 写入后，query 才读取输出。因此 residual 依赖使用严格下三角，而 output interaction 包含对角线。

在 chunk 内展开衰减

定义 cumulative log-decay：

Gi := Σm=0..igm

token i 在写入自身 residual 前看到的状态：

S̄i = exp(Gi)Sin + Σj<iexp(Gi−Gj)kjrjᵀ

所以 residual 为：

ri = βi[vi − exp(Gi)kiᵀSin − Σj<iexp(Gi−Gj)(kiᵀkj)rj]

2｜Decay 进入严格下三角 Gram

定义两个 mask：

M<

1[j<i]

residual 依赖；严格下三角。

M≤

1[j≤i]

output 读取；包含对角线。

相对衰减矩阵仍是 exp(Gᵢ−Gⱼ)。将它乘到 key Gram：

Lij := 1[j<i]·exp(Gi−Gj)·(kiᵀkj)

再定义按 token 行缩放的 key：

Kg := K ⊙ exp(G)    [C,K]

因为第 i 行的 incoming-state prediction 是：

exp(Gi)kiᵀSin = (KgSin)i

堆叠 residual

令 B=diag(β)，就得到：

R = B·(V − KgSin − L·R)
(I+B·L)R = B(V−KgSin)

定义：

A−1 := (I+B·L)−1
T := A−1B

然后：

U := T·V
W := T·Kg
R = U − W·Sin
为什么 FLA 看起来少了 B？

FLA 先计算 v ← βV、k_beta ← βK，再用 A⁻¹ 左乘。因此 A⁻¹(βV)=TV=U，A⁻¹(βK_g)=TK_g=W。β 被预先折叠进输入了。

3｜Output 与 final state 使用不同权重

Output：每一行衰减到自己的位置

定义包含对角线的 weighted QK matrix：

Pij := 1[j≤i]·exp(Gi−Gj)·(qiᵀkj)

同时，incoming state 对第 i 个 query 衰减了 exp(Gᵢ)，定义：

Qg := Q ⊙ exp(G)

于是：

O = QgSin + P·R = QgSin + P(U−WSin)

Final state：所有更新都衰减到 chunk 末尾

定义：

Kend,j := exp(Glast−Gj)kj

则：

Sout = exp(Glast)Sin + KendᵀR

代入 WY residual：

Sout = [exp(Glast)I − KendᵀW]Sin + KendᵀU
一个 chunk = 一个 affine transfer

即使加入 scalar decay 和 delta correction，chunk 对 incoming state 仍可写成 S_out = M_state·S_in + B_state。这为 chunk scan、Context Parallel 和 kernel 分阶段提供了基础。

4｜逐行映射 FLA naive 实现

打开本地 naive_chunk_gated_delta_rule，按下面顺序阅读。

① 预处理 β 与 chunk cumsum

v = v * beta[..., None]               # βV
k_beta = k * beta[..., None]           # βK
decay = decay.cumsum(-1)               # G
L_mask = exp(G_i - G_j).tril()         # relative decay × M≤

② 构造严格下三角依赖并求 A⁻¹

attn = -((k_beta @ k.T) * L_mask)
attn = attn.masked_fill(diagonal_and_upper, 0)

# 逐行累积严格下三角 inverse
for i in range(1, chunk_size):
    attn[i, :i] += ...

attn = attn + I                        # A⁻¹

代码把负号吸收进 inverse recurrence；不要仅凭 attn 名字判断它是普通 attention score。

③ 准备 U/W

U = attn @ (beta * V)                  # k_cumsum
W = attn @ (beta * exp(G) * K)         # k_cumdecay

④ 注入 incoming state，得到真正 residual

prediction = W @ S_in                  # v_prime
R = U - prediction                     # v_new

⑤ 计算 output 与 final state

P = tril((Q @ K.T) * exp(G_i - G_j))
O = (Q * exp(G)) @ S_in + P @ R

K_end = K * exp(G_last - G)
S_out = exp(G_last) * S_in + K_end.T @ R

5｜最小 PyTorch 公式骨架

def one_chunk_gated_delta(q, k, v, g, beta, state_in):
    C = q.shape[0]
    G = g.cumsum(0)
    strict = torch.tril(torch.ones(C, C, device=q.device), -1)
    causal = torch.tril(torch.ones(C, C, device=q.device))
    rel = (G[:, None] - G[None, :]).exp()

    L = (k @ k.T) * rel * strict
    B = torch.diag(beta)
    A = torch.eye(C, device=q.device) + B @ L
    Ainv = torch.linalg.solve_triangular(
        A, torch.eye(C, device=q.device), upper=False
    )

    U = Ainv @ (beta[:, None] * v)
    Kg = k * G.exp()[:, None]
    W = Ainv @ (beta[:, None] * Kg)
    R = U - W @ state_in

    P = (q @ k.T) * rel * causal
    Qg = q * G.exp()[:, None]
    out = Qg @ state_in + P @ R

    Kend = k * (G[-1] - G).exp()[:, None]
    state_out = G[-1].exp() * state_in + Kend.T @ R
    return out, state_out

这不是性能实现，而是 correctness oracle。进入 Triton 前，必须先让它与逐 token recurrent 在 full chunk、tail chunk、initial state、极端 gate 上一致。

数值与性能伏笔

实际 kernel 会避免显式保存多个 C×C 矩阵，可能把 exp 转为 exp2，并使用局部 offset 控制范围。FlashKDA 选择 chunk=16，也与 gate 数值范围和小三角 inverse 成本直接相关。
