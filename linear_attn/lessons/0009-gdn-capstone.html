1｜三题热身

1. Recurrent state 最自然的 grid 并行轴是什么？
2. FLA 哪个阶段 chunk-serial？
3. FlashInfer SM103 不保存完整 H/R 的核心原因？

2｜代码题：一个正确的 GDN step

实现 V-first state 的执行顺序：

decay
→ prediction
→ residual
→ rank-1 state update
→ output from updated state

要求输入 state 不被原地修改。测试会故意使用非零 initial state，以暴露漏掉 decay 或顺序错误。

3｜Grid 计算题

给定：

B=2, T=256, H=8, C=64, V=128, BLOCK_V=16

你需要返回：

NT
Gate/KKT programs
Solve programs
W/U programs
State programs
Output programs
FlashInfer logical tiles

判断原则只有两条：grid 含 NT 就跨 chunk 并行；kernel 内 for NT 就是 chunk-serial。

4｜四个工程问答

  1. 为什么 FLA 保存 H 和 R，而 SM103 通常不保存？
  2. FLA state scan 哪些维度仍然并行？
  3. 普通 SM90 与 SM103 的 state storage / warp 调度有何不同？
  4. Lesson 7 第一次 fusion 前应收集什么 profile 证据？

每题 2–5 句，重点是因果关系，不要求复述课程原文。
