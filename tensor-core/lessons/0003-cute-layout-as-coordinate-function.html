Layout 是一个坐标函数

看到 shape:stride，先手算映射，再谈 tiling、Copy Atom 和 MMA Atom。

这节课的唯一目标 (tangible win) 给定一个 CuTe Layout，例如 (128,8):(1,132)，你能写出它的坐标函数，判断哪个 mode 连续、是否存在 padding 或地址别名，并审查 Agent 对它的口头解释。

0. 从第二课取回一个旧知识

第二课中，你已经手写过一种 Layout，只是当时没有这个名字：

g = lane_id / 4;  t = lane_id % 4;
(lane_id, value_id)  ──→  C/D 的 (m,n) 坐标

mma.sync fragment 规定了“线程—寄存器槽 → 矩阵坐标”的映射；C 写回公式又把矩阵坐标映射到线性地址。CuTe 用同一种语言——Layout——统一描述这些映射。

逻辑坐标
(i,j)
Layout →
整数坐标
offset
先拆掉一个常见误解 Layout 本身不知道 global/shared/register，也不知道“行”和“列”。它只是整数函数。输入输出的语义和单位由上下文决定：可以是 tensor 坐标 → element offset，也可以是 (thread,value) → fragment 坐标。[1]

1. 读懂 shape:stride

二维 Layout 记作：

L = (S₀,S₁):(d₀,d₁)
L(i,j) = i × d₀ + j × d₁       0 ≤ i < S₀, 0 ≤ j < S₁

S₀/S₁ 给出坐标域，每一维在 CuTe 中称为一个 mode；d₀/d₁ 表示对应坐标增加 1 时，输出整数增加多少。不要看到两个 mode 就自动命名为 row/column——先从 tensor 语义确认。

Layout坐标函数结论
(4,3):(3,1)L(i,j)=3i+jmode 1 连续；若 (i,j)=(row,col)，这是 row-major。
(4,3):(1,4)L(i,j)=i+4jmode 0 连续；若语义同上，这是 column-major。
(4,3):(1,8)L(i,j)=i+8jmode 0 连续；相邻 mode-1 切片之间有 4 个空洞。
(4,3):(0,1)L(i,j)=jmode 0 被广播；不同 i 会映射到同一位置。

这里有两个不同的量：

  • size(L)：逻辑坐标个数，二维平坦 shape 下是 S₀×S₁。
  • cosize(L)：覆盖该 Layout 输出所需的地址跨度；对本课的非负 stride，可算作 max L(i,j)+1。有 padding 时它可能大于 size。[1]

2. 用探针建立直觉

先选一个 preset，再点任意逻辑坐标。红线表示至少两个逻辑坐标映射到了同一 offset；这对只读广播可能有意，对并行写入通常意味着冲突或数据竞争。

审查 Layout 的最小算法 ① 给每个 mode 命名；② 写出 L(coord)；③ 分别让每个坐标加 1，看 offset 增量；④ 查 alias；⑤ 比较 size 与 cosize，找 padding。不要只凭“看起来像 row-major”下结论。

3. 审查真实 CuTe DSL 代码

打开 mma_atom.py，找到：

smem_layout_a = cute.make_layout(
    shape=(tile_m, tile_k),
    stride=(1, tile_m + 4)
)
# tile_m=128, tile_k=8 → (128,8):(1,132)
审查问题推导
坐标函数L(m,k)=m+132k。
连续 modem 增加 1，offset 增加 1；所以 M mode 连续。
padding一个 K 切片有 128 个有效元素，下一个切片从 offset 132 开始，中间留下 4 个元素。
size128×8=1024 个逻辑元素。
cosize最大 offset 是 127+132×7=1051，所以地址跨度为 1052 个元素。

这 4 个 padding 元素不是“自动消除 bank conflict”的证明。它只改变了跨 K 切片的地址关系；是否无 bank conflict，仍需结合实际 warp 访问坐标与 bank 映射验证。

即时回忆 1：对 (4,3):(3,1)，坐标 (2,1) 映射到哪个 offset？

直接代入 L(i,j)=3i+j，得到 L(2,1)=7。

即时回忆 2：Layout (4,3):(0,1) 最需要警惕什么？

L(i,j)=j 与 i 无关，因此不同的第一维坐标会落到同一 offset。
