Layout 读码速查

把任何 shape:stride 还原成可审查的整数函数。

L = (S₀,…,Sₙ):(d₀,…,dₙ)
L(c₀,…,cₙ) = Σ cᵢdᵢ,    0 ≤ cᵢ < Sᵢ
语义来自上下文 Layout 只描述整数映射。坐标可以表示 tensor 的 (m,n)，也可以表示 (thread,value)；输出可以是 element offset、bit offset 或另一个逻辑坐标。先命名 mode，再做计算。

五步审查法

  1. 命名 mode：确认每一维表示 M/N/K、thread/value、stage，还是别的层次。
  2. 写函数：把 shape:stride 展开为 L(coord)，不要凭视觉猜 row/column major。
  3. 测增量：单独让第 i 个坐标加 1；offset 增量就是该 mode 的 stride。
  4. 查唯一性：寻找不同合法坐标是否映射到同一输出。stride 0 不必然 alias；若对应 shape 为 1，只有一个合法坐标。
  5. 查跨度：比较逻辑元素数 size 与地址跨度 cosize，识别 padding、空洞与存储预算。

常见二维模式

Layout函数读法
(M,N):(N,1)Ni+j若 mode=(row,col)，则 row-major。
(M,N):(1,M)i+Mj若 mode=(row,col)，则 column-major。
(M,N):(1,L)i+LjM mode 连续；当 L>M 时切片间有 padding。
(M,N):(0,1)j当 M>1 时沿 mode 0 广播并产生 alias。

size 与 cosize

对本阶段常见的非负 stride：

size(L)   = ∏ Sᵢ
cosize(L) = 1 + Σ (Sᵢ - 1)dᵢ

size 是逻辑坐标数；cosize 是覆盖最大输出坐标所需的跨度。它们相等不自动证明映射唯一，不相等也不自动说明错误。

Agent 审查红旗

  • 没有先说明 mode 语义，就断言“这是 row-major”。
  • 看到 padding 就直接断言“没有 shared-memory bank conflict”。
  • 看到 stride 0 就直接断言存在 alias，没有检查对应 shape。
  • 用 size 分配实际存储，但 Layout 的 cosize 更大。
  • 把 Tensor Layout 和 Thread–Value Layout 当成同一种坐标语义。
